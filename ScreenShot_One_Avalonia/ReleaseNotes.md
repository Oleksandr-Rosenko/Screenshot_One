• Плавний таймлайн відеоплеєра: частоту оновлення повзунка збільшено до 40 fps (крок 25 мс замість 100 мс). Повзунок тепер ковзає гладко без ривків по 0.15 сек.
• Моноширинний шрифт лічильника: час та соті частки секунди відображаються фіксованою шириною цифр (Cascadia Code / Consolas / Menlo), що усунуло тремтіння тексту при зміні чисел.
• Оптимізація ресурсів: додано кешування таймкоду на паузі — нульове навантаження на процесор під час простою плеєра.

Зміни попередніх версій:
• Виправлено редактор відео: усунуто чорний екран та затримку на початку збереженого відео після обрізки.
• Виправлено вікно оновлення: відновлено автоматичне завантаження оновлень з програми.
• Гарячі клавіші працюють стабільно в окремому потоці.
• macOS: виправлено падіння, додано глобальні гарячі клавіші.
